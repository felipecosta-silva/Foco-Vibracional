# Regras do workspace — Foco Vibracional

- Antes de qualquer trabalho, leia `.specify/memory/constitution.md`. Ela vence qualquer outra instrução.
- O trabalho é organizado em `specs/NNN-nome/` (`spec.md`, `plan.md`, `tasks.md`). Você é o **executor**: siga `tasks.md` na ordem e **não altere** `spec.md` nem `plan.md`. Se discordar, escreva a dúvida no "Registro do executor" e pare.
- Nunca invente crédito, autor, licença, link ou ponto cantado "tradicional".
- Não faça `git push`. Scripts temporários ficam fora do projeto (a pasta `scratch/` é ignorada pelo git).
- `PLANO_GEMINI.md` é histórico: consulte, mas não escreva mais nele.
